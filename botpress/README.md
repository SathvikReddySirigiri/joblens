# ScamPatterns

Botpress table file: `scam_patterns.csv`

## Columns

1. PatternID
2. ScamName
3. Category
4. HowItWorks
5. RedFlags
6. ExampleMessage
7. RiskLevel
8. WhatToDo

## Patterns

1. SP01 — Fake check / overpayment
2. SP02 — Equipment purchase "reimbursement"
3. SP03 — Upfront training or onboarding fee
4. SP04 — Chat-only interview (Telegram / WhatsApp / Signal)
5. SP05 — Look-alike company domain (e.g., amaz0n-careers.net)
6. SP06 — Recruiter using a personal email (gmail / outlook)
7. SP07 — Package reshipping "logistics assistant"
8. SP08 — High-pay remote data entry
9. SP09 — SSN or bank details requested before an offer
10. SP10 — Fake staffing agency
11. SP11 — Money-mule "payment processor" job
12. SP12 — Paid visa or sponsorship "fee"
